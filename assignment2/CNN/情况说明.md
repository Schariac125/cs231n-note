# 情况说明CNN篇

## 1.CNN概述

CNN，也就是卷积神经网络，卷积神经网络相对于我们先前搓的全连接神经网络（FC）优越了不少。首先 CNN 承认了输入的图像是一个多维的数组的事实，并不在第一层就直接将一整个数组全部展开成一列，而是通过定义卷积核，用卷积核进行扫描，然后得到一个新的特征图，传入下一层再进行扫描

在这个过程中 CNN 会逐渐建构起一个关于图像的整体概念，例如说在第一层扫描的时候，它只能意识到这是一条线，第二层它可能就能猜出来，这可能是一根头发或者一根胡须，第三层就更加深入等等。有着非常明显的层级概念。并且由于卷积核是对图像的局部进行扫描，所以它可以观测到任何一个地方的某个特征，受到位置的影响非常小。

CNN 的核心机制之一是参数共享，正是这个机制使得 CNN 的参数量比起普通的全连接神经网络小了非常非常多，一个卷积核定义了一个特征，那么这个参数在整个图像上都是共用的。而比较起普通的全连接神经网络，它不用使用参数去知道左上角有个“眼睛”，也不用再去知道右下角有个“眼睛”，这个参数是共用的。这是一个非常重要的特性，不仅保证了它在高清图像上的发挥同时也更加灵活，属于是一举两得。

CNN 有一个非常重要的层，也就是池化层，池化层的其实是在做进一步的提纯，这个层后会把特征图尺寸进一步缩小。只会保留它认可的最重要的特征。从理论上讲，这个做法确实可以让神经网络更好的关注整体特征，而不是在某个细节上死抠半天。但是，你知道的，一切对信息做提纯的方式都会有副作用。池化层有破坏掉原本数据的一面，因此现在有些论文中指出了不该使用池化层，但这是后话。

## 2.代码实现中存在的问题

### 0 填充的实现

CNN 有一个很重要的任务就是去做 0 填充，很直观的思路是直接用一个 for 循环在外层直接加上对应层数的 0 ，但是事实上，这种方法本质上是一个很变态的模拟，容易把自己绕晕，因此我们需要一个更好的方法去做这件事。

cs231n 中告诉我们可以使用 `np.pad` 这个方法进行填充，就像下面这样
`X_padded = np.pad(x, ((0, 0), (0, 0), (1, 1), (1, 1)), mode="constant",constant_values=0)`

~~这个是我查了 AI 才知道怎么用的~~

constant 表示填充的对象是一个常数，默认是 0 ，但是也可以通过后面那个参数去指定填充的数值，这不是很重要。

首先，因为 CNN 是局部连接的，所以它的 dx ，dw ，db 等等都是累加上去的，而我们要做的就是把那些个卷积核拿出来，然后按照那个公式去写，就是以前推导出来的那个通用的公式。

因为这东西是累加的，所以我们在一开始就要去把这三个要求的变量全部初始化成完全的 0 矩阵，并且对于 dx 我们还要把他变成 0 填充之后的样子，最后再把他还原。

事实上最难想的就是这东西为什么是累加的，想清楚这个了感觉就不是很难的事情。
