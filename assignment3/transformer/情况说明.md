# Transformer 情况说明

## 0.简介

transformer 抛弃了传统 RNN 的那一套顺序处理，换取的是更高的上限，它不再让每一个词只去盯着前面的一个两个，而是每一个词都会去“注意”到。这个就是最核心的自注意力机制了。

## 1.自注意力机制

自注意力机制就是 transformer 与 RNN 划清界线的最主要机制。传统的 RNN 中，词需要通过那个隐藏状态 $h$ 来知道前面发生了什么，但在 transformer 中，每一个词都有一个“雷达”，可以去捕获与其他词的相关性。也就是“注意力”

单个 transformer 层可能有非常多的注意力头，每一个注意力头都会负责一个特征的捕获。在本次作业中的数量一般是被定义为 H。

我们需要在原本的 Q K V 三个矩阵中添加一个大小为 H 的维度，这就表示注意力头。按照公式，这时候就该拉着 Q 和 K 做点积了，最后再乘上 V 。

一般而言，我们目前这样子得到的结果就是把多个注意力头得到的向量硬生生拼在一起，然后再去过一遍 softmax 和 dropout 。这些操作结束之后需要乘上 V。

在具体的代码实现中，这个过程结束之后其实还只是一串没啥意义的普通矩阵，需要再去过一次线性变换才行。

需要注意的是，我们在这个过程中除以了一个参数 $\sqrt{\frac{d}{h}}$ ，除以这个参数的作用是为了防止梯度消失。

## 2.transformer 解码器

transformer 解码器包含三个模块。
- 自注意力模块，用于处理输入的向量序列
- 交叉注意力模块，用来整合可用的上下文，
- 前馈模块，独立处理序列中的每个向量。

实际上……这个说着好像很高深，但是就是几个函数调来调去，然后把算出来的结果加回去，再过一遍变换层的事情……

具体的代码实现长这样

```python
# 自注意力块（参考实现）
shortcut = tgt
tgt = self.self_attn(query=tgt, key=tgt, value=tgt, attn_mask=tgt_mask)
tgt = self.dropout_self(tgt)
tgt = tgt + shortcut
tgt = self.norm_self(tgt)

tgt2 = self.cross_attn(query=tgt, key=memory, value=memory)
tgt2 = self.dropout_cross(tgt2)
tgt = tgt + tgt2
tgt = self.norm_cross(tgt)
tgt2 = self.ffn(tgt)
tgt2 = self.dropout_ffn(tgt2)
tgt = tgt + tgt2
tgt = self.norm_ffn(tgt)
```
## 3.transformer 编码器

编码器包含了以下几个模块
- 多头自注意力模块
- 前馈神经网络模块

而这个多头注意力模块其实就是在做上面的那个公式，输出结果并融合。然后前馈神经网络模块可能就会使用一些全连接层或者是激活函数。

## 4.残差连接和归一化

这两个操作无论是解码器还是编码器都是有的，残差连接就是上面的把得到的结果加回去。
归一化主要是层归一化，保证数据稳定来的。

## 5.完整架构

1. 输入预处理，这个阶段会对数据做一些基本的向量化操作，例如词嵌入。同时位置编码也发生在这个阶段。可能也会使用 dropout 丢弃一些神经元。
2. 编码器，负责深度理解。
3. 解码器，负责解读编码器传来的数据。预测下一个词输出什么

## 6.总结

Transformer 是一个基于多头并行算力、依靠注意力机制建立全局索引、通过残差与归一化保证深度堆叠稳定性的“并行流水线”。
